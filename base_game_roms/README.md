# Base game ROMs

This directory is **gitignored**. Place ROMs here, do not commit them.

Required:

- `Legend of Zelda, The - A Link to the Past (U) [!].smc` — clean US dump.
  Headerless. This is the only ROM the build pipeline reads.

Optional:

- `Zelda no Densetsu - Kamigami no Triforce (J) (V1.0).smc` — Japanese original.
  Reference only; not read by the build.
